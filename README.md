# Hamstr

**[Hamstr](https://gethamstr.com)** turns your lecture PDFs into spaced-repetition flashcards in seconds.

- Website: [gethamstr.com](https://gethamstr.com)
- Use it in your browser: [app.gethamstr.com](https://app.gethamstr.com)
- Download for Mac: [latest release](https://github.com/bardya07/hamstr-releases/releases/latest)

This repository hosts signed Hamstr for Mac release builds.
